macOS：
  1. 解压，把 Gravity.app 拖进「应用程序」。
  2. 首次打开若被拦截：右键 → 打开 → 打开。
  3. 打开后复制机器码，向作者获取激活码。

说明：
  - 未做 Apple 公证与 Windows 代码签名，首次运行可能出现系统警告。
  - 激活码绑定机器码，重装系统或换主板后机器码会变化。
  - 定位为城市级估算，不保证每个应用读取同一来源。
