macOS：
  1. 解压，把 Gravity.app 拖进「应用程序」。
  2. 首次打开若被拦截：右键 → 打开 → 打开。
  3. 打开后复制机器码，向作者获取激活码。

本版新增：
  - 环境页新增「Claude 账号 KYC 状态」查询（独立登录窗口，非公开接口，仅供参考）。

  - 激活码绑定机器码，重装系统或换主板后机器码会变化。
