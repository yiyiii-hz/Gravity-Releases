Gravity 1.0.8

文件：
  Gravity-1.0.8-macOS-arm64.zip          macOS 12+ / Apple Silicon
  Gravity-1.0.8-Windows-x64-Setup.exe    Windows 10/11 x64 安装包
  Gravity-1.0.8-Windows-x64-Portable.zip Windows 10/11 x64 免安装版
  SHA256SUMS.txt                          校验和

macOS：
  1. 解压，把 Gravity.app 拖进「应用程序」。
  2. 首次打开若被拦截：右键 → 打开 → 打开。
  3. 打开后复制机器码，向作者获取激活码。

Windows：
  1. 运行安装包，或解压免安装版后运行 Gravity.exe。
  2. 输入机器码对应的激活码。
  3. 在「持久化」页按三步引导完成一次系统位置增强初始化。
  4. 检测网络出口并应用定位。

本版新增：
  - 新增代理控制器只读接入，自动读取 TUN、DNS、IPv6 与 Claude 分流状态。
  - 自动识别 Claude 组、当前第二跳、MATCH 与 UDP 策略，减少人工确认。
  - 设置页可填写控制器地址与密钥。
  - 版本号更新为 1.0.8。

说明：
  - 定位是城市级估算，不保证每个应用看到的位置完全一致。
  - 需要管理员授权才能写入系统定位。
  - 未做 Apple 公证 / Windows 代码签名，首次运行可能有系统警告。
  - 请仅在你有权管理的设备上使用。
