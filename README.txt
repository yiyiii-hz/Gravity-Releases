macOS：
  1. 解压，把 Gravity.app 拖进「应用程序」。
  2. 首次打开若被拦截：右键 → 打开 → 打开。
  3. 打开后复制机器码，向作者获取激活码。

Windows：
  1. 运行安装包，或解压免安装版后运行 Gravity.exe。
  2. 输入机器码对应的激活码。
  3. 在「持久化」页按三步引导完成一次系统位置增强初始化。
  4. 检测网络出口并应用定位。

本版新增：
  - 修复 DNS 泄露检测：直接使用真实探测结果，检查全部解析器，避免误判为通过。
  - 网络环境自查不再需要打开网页。
  - 版本号更新为 1.0.4。

说明：
  - 定位是城市级估算，不保证每个应用看到的位置完全一致。
  - 需要管理员授权才能写入系统定位。
  - 未做 Apple 公证 / Windows 代码签名，首次运行可能有系统警告。
  - 请仅在你有权管理的设备上使用。
