macOS：
  1. 解压，把 Gravity.app 拖进「应用程序」。
  2. 首次打开若被拦截：右键 → 打开 → 打开。
  3. 打开后复制机器码，向作者获取激活码。

本版新增：
  - KYC 查询改为粘贴 claude.ai 整段 Cookie（不再内嵌登录窗口，Cookie 只放在内存临时分区、查完即清、不落盘不记日志）。
  - 修复登录窗口无法关闭。
  - 识别 verified 状态。
  - 修复 Cookie 被覆盖导致 403。
  - 启动时清除旧版登录残留。

说明：
  - 第一跳和第二跳都由客户自行购买，Gravity 只生成配置模板；不承诺防封、不承诺通过风控。
  - 未做 Apple 公证与 Windows 代码签名，首次运行可能出现系统警告。
  - 激活码绑定机器码，重装系统或换主板后机器码会变化。
  - 定位为城市级估算，不保证每个应用读取同一来源。
